Automated Scheduling Data Pipeline (Kriteria Big Data)

Seluruh data indikator ekonomi makro di bawah disinkronisasikan secara otomatis menggunakan background service scheduler:
• Daily Schedule (Cron): Scraping massal ke situs resmi Bank Indonesia dijalankan otomatis setiap hari pada pukul 00:05 WIB.
• Hourly Schedule (Interval): Pengecekan interval berkala dijalankan setiap 1 jam sekali untuk memperbarui data real-time apabila Bank Indonesia merilis rilis pers baru di siang hari.
• On-Demand Sync (Reactive): Jika jadwal terlewat (misal: server direstart), sistem akan pintar mendeteksi data usang dan langsung memaksa sinkronisasi secara diam-diam saat halaman ini dibuka perdana.
